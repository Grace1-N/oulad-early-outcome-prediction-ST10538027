# oulad-early-outcome-prediction-ST10538027
Early prediction of student outcomes (pass/fail) in open university settings using OULAD engagement and assessment data at Weeks 2, 4 and 6, comparing Logistic Regression, Random Forest and XGBoost. Research project (RPDA8412), ST10538027. Derived code and analytical outputs only; the original OULAD dataset is not rehosted.
